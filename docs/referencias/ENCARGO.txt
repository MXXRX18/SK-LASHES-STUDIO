1. OBJETIVO Y DIRECCIÓN CREATIVA

SK Lashes Studio es un estudio de estética enfocado en servicios de pestañas. La web debe transmitir precisión, elegancia, seriedad, confianza y alto prestigio mediante su diseño. Combina Cinematic Design con Glassmorphism de forma contenida: fotografía protagonista, iluminación dramática suave, profundidad visual, espacios amplios, títulos expresivos y superficies translúcidas discretas.

La experiencia debe sentirse diseñada para esta marca. Evita la apariencia de plantilla de salón, dashboard, ecommerce o landing genérica. El lujo debe percibirse en la fotografía, la jerarquía y los detalles, sin llenar la página de adjetivos.

Paleta propuesta, centralizada en variables de diseño:
- Negro profundo: #100D10, base principal.
- Ciruela oscuro: #24151E, profundidad y superficies secundarias.
- Rosa vino: #7B294C, acento principal y acciones.
- Rosa malva: #B56D88, pequeños detalles y acentos de apoyo.
- Blanco cálido: #F7F3F5, texto y secciones claras puntuales.

Usa degradados tonales muy suaves entre negro, ciruela y rosa vino. Evita grandes superficies de rosa plano, neón, rosa infantil, brillos exagerados, partículas, corazones o decoración que reste seriedad. Verifica el contraste de cada combinación; el acento rosa no debe comprometer la lectura.

Combina una serif editorial elegante para titulares con una sans serif limpia para cuerpo, precios, navegación y formulario. Como referencia estética, Cormorant Garamond e Inter, si sus licencias y archivos permiten incorporarlas correctamente. Usa como máximo dos familias. Mantén letras grandes y legibles; evita cursivas extensas y pesos demasiado finos en tamaños pequeños.

Diseña con una retícula consistente, alineaciones precisas y espacios generosos. Usa separadores finos y cambios sutiles de fondo para organizar el contenido. Reserva el cristal para navegación, controles del carrusel y, si mejora la composición, una única superficie de formulario. No encierres todas las secciones en tarjetas. Mantén un fondo suficientemente opaco para leer el texto y ofrece fallback cuando backdrop-filter no esté disponible.

5. GALERÍA: REUTILIZAR EL CARRUSEL SUMINISTRADO

El ANEXO A contiene el HTML, CSS y JavaScript del carrusel aportado por el cliente, normalizado para eliminar barras de escape del texto original. Debe ser la base obligatoria de la galería. No lo sustituyas por un slider genérico ni por una biblioteca que cambie su composición.

Conserva su carácter horizontal: fotografía central nítida, imágenes laterales más pequeñas y desenfocadas, transiciones combinadas de desplazamiento, escala, opacidad y blur, controles anterior/siguiente, navegación por flechas del teclado y gestos táctiles.

Conserva como referencia las escalas 1 / 0.85 / 0.70, opacidades 1 / 0.65 / 0.18, desenfoques 0 / 3 / 8 px y duración de transición próxima a 800 ms. Ajusta medidas, radios, sombras, controles y contraste a la identidad de SK Lashes Studio.

La navegación circular manual del código está permitida. No agregues autoplay, movimiento perpetuo, marquesinas, carruseles adicionales ni sliders flotantes infinitos. Las fotografías solo cambian por una acción explícita del visitante.

Adapta el bloque al framework elegido con componentes, estado y limpieza de efectos/listeners/temporizadores. No pegues un script global que se ejecute repetidamente ni manipules nodos de React de manera que entren en conflicto con su estado.

Revisa y corrige estos detalles sin perder la apariencia original:
- Evitar cruces y saltos visibles al pasar entre la última y primera imagen, incluidos clics rápidos.
- Evitar que la clase «salto» deje fotos temporalmente sin animación cuando vuelvan a ocupar posiciones visibles.
- Controles táctiles de al menos 44 × 44 px, aunque el código base use botones menores.
- No capturar deslizamientos verticales como cambios de fotografía; comparar desplazamientos horizontal y vertical.
- No permitir que fotos invisibles intercepten clics o reciban el foco.
- Mantener navegación accesible, foco visible, etiquetas descriptivas y anuncio breve de la imagen activa; no trasladar el foco inesperadamente al cambiar.
- Sustituir los textos alt genéricos por descripciones reales de las imágenes elegidas.
- Respetar prefers-reduced-motion en CSS y en cualquier temporización JavaScript.
- Mostrar un estado visual cuidado si una imagen falla, sin iconos de imagen rota.

6. AGENDA EN PÁGINA INDEPENDIENTE

En Inicio, la sección «Agenda una cita» tendrá solo un titular breve, una frase y el enlace a /agendar en nueva pestaña.

La página /agendar debe conservar la identidad del sitio y presentar un formulario limpio, sin distracciones, con los siguientes campos obligatorios:
- Primer nombre: caja de texto con etiqueta visible.
- Primer apellido: caja de texto con etiqueta visible.
- Servicio: selección múltiple accesible de 1 a 5 servicios distintos, mediante casillas de verificación o un control equivalente fácil de usar en móvil. Mostrar nombre y precio, además de un contador «0 de 5 seleccionados». Al llegar a cinco, impedir nuevas selecciones y permitir desmarcar cualquiera.
- Día de preferencia: campo de fecha con calendario para seleccionar una fecha específica. No permitir fechas anteriores al día actual del usuario. Evitar errores de zona horaria al interpretar YYYY-MM-DD.

Acepta nombres con acentos, ñ, espacios, apóstrofos y guiones. Elimina espacios sobrantes sin imponer reglas que rechacen nombres válidos. Usa mensajes de error breves, junto a su campo y accesibles para lectores de pantalla. Conserva los datos si hay un error.

El formulario NO muestra horarios disponibles, NO reserva espacios y NO confirma automáticamente citas. No añadas campos de hora, correo, teléfono u otros datos no solicitados. No se necesita base de datos ni panel administrativo para este alcance.

Muestra cerca del botón:
«Tu solicitud está sujeta a disponibilidad. Confirmaremos tu cita por WhatsApp.»

Botón final: «Continuar en WhatsApp».

9. ANIMACIONES DE SCROLL EN AMBAS DIRECCIONES

Aplica apariciones suaves al entrar en el viewport: opacidad de 0 a 1, blur de 6–8 px a 0 y desplazamiento vertical de aproximadamente 16–24 px. Usa duraciones de 550–800 ms y desfases cortos de hasta 120 ms entre elementos relacionados.

El efecto debe repetirse al regresar a una sección tanto bajando como subiendo. Reinicia el estado solo cuando el elemento haya salido completamente del viewport, y usa un umbral de entrada que evite parpadeos en los bordes. Mantén visible cualquier elemento con foco de teclado y su contexto.

Usa IntersectionObserver o una solución equivalente ligera. No uses scroll hijacking, movimiento obligado, parallax intenso, animaciones de página completa ni listeners que recalculen todos los elementos en cada píxel. Evita animar continuamente filtros costosos.

Aplica el reveal al contenedor externo del carrusel para no sobrescribir los transforms que posicionan sus fotografías. Al finalizar cada aparición, deja texto e imágenes totalmente nítidos. Con movimiento reducido, muestra el contenido sin desplazamientos ni desenfoques animados. Si JavaScript falla, el contenido principal debe seguir visible.

10. PRECARGA SKELETON

Implementa skeletons discretos que respeten las dimensiones reales de imágenes o contenido pendiente. No uses una pantalla de carga que bloquee toda la web ni contadores ficticios.

Retíralos tan pronto esté disponible el contenido y, como límite de la espera visual controlada por la interfaz, antes de dos segundos desde su render. No impongas una espera artificial de dos segundos. Si una imagen tarda más, deja visible el resto de la página y usa un fondo o fallback estable hasta que llegue. Un skeleton no puede garantizar que una conexión lenta termine de descargar en dos segundos.

Evita destellos, transiciones de blanco a negro y cambios de altura. Con prefers-reduced-motion, desactiva el shimmer. No ocultes textos y acciones que ya pueden mostrarse.

<script>
(() => {
  const carrusel = document.getElementById("carrusel-horizontal");
  if (!carrusel) return;
  const fotos = Array.from(carrusel.querySelectorAll(".carrusel-h__foto"));
  const botonAnterior = carrusel.querySelector(".anterior");
  const botonSiguiente = carrusel.querySelector(".siguiente");
  const total = fotos.length;
  if (total === 0) return;
  let actual = 0;
  let inicioX = 0;
  let ultimoDeslizamiento = 0;
  const temporizadores = new WeakMap();

  function posicionRelativa(indice) {
    let posicion = (indice - actual + total) % total;
    if (posicion > Math.floor(total / 2)) posicion -= total;
    return posicion;
  }

  function actualizar() {
    fotos.forEach((foto, indice) => {
      const posicion = posicionRelativa(indice);
      const distancia = Math.abs(posicion);
      const escala = distancia === 0 ? 1 : distancia === 1 ? 0.85 : 0.70;
      const opacidad = distancia === 0 ? 1 : distancia === 1 ? 0.65 : distancia === 2 ? 0.18 : 0;
      const desenfoque = distancia === 0 ? 0 : distancia === 1 ? 3 : 8;
      const desplazamiento = posicion * 65;
      const posicionAnterior = foto.dataset.posicion;
      if (posicionAnterior !== undefined && Math.abs(Number(posicionAnterior) - posicion) > 1) {
        foto.classList.add("salto");
        clearTimeout(temporizadores.get(foto));
        const temporizador = setTimeout(() => foto.classList.remove("salto"), 820);
        temporizadores.set(foto, temporizador);
      }
      foto.style.setProperty("--x", desplazamiento + "%");
      foto.style.setProperty("--escala", escala);
      foto.style.setProperty("--opacidad", opacidad);
      foto.style.setProperty("--desenfoque", desenfoque + "px");
      foto.style.setProperty("--profundidad", total - distancia);
      foto.dataset.posicion = posicion;
      foto.tabIndex = distancia === 0 ? 0 : -1;
      if (distancia === 0) foto.setAttribute("aria-current", "true");
      else foto.removeAttribute("aria-current");
    });
  }

  function cambiar(direccion) {
    actual = (actual + direccion + total) % total;
    actualizar();
  }

  botonAnterior.addEventListener("click", () => cambiar(-1));
  botonSiguiente.addEventListener("click", () => cambiar(1));
  fotos.forEach((foto, indice) => {
    foto.addEventListener("click", () => {
      if (Date.now() - ultimoDeslizamiento < 500) return;
      const posicion = posicionRelativa(indice);
      if (posicion === -1 || posicion === 1) cambiar(posicion);
    });
  });
  carrusel.addEventListener("keydown", (evento) => {
    if (evento.key === "ArrowRight") {
      evento.preventDefault();
      cambiar(1);
    }
    if (evento.key === "ArrowLeft") {
      evento.preventDefault();
      cambiar(-1);
    }
  });
  carrusel.addEventListener("touchstart", (evento) => {
    inicioX = evento.changedTouches[0].clientX;
  }, { passive: true });
  carrusel.addEventListener("touchend", (evento) => {
    const finX = evento.changedTouches[0].clientX;
    const diferencia = inicioX - finX;
    if (Math.abs(diferencia) > 50) {
      ultimoDeslizamiento = Date.now();
      if (diferencia > 0) cambiar(1);
      else cambiar(-1);
    }
  }, { passive: true });
  actualizar();
  requestAnimationFrame(() => {
    requestAnimationFrame(() => carrusel.classList.add("lista"));
  });
})();
</script>
